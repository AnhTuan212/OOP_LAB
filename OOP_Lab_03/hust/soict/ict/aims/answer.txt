Question: Reading Assignment: Please answer three questions below:
- What are the advantages of Polymorphism?
- How is Inheritance useful to achieve Polymorphism in Java?
- What are the differences between Polymorphism and Inheritance in Java?
Answer: Advantages of Polymorphism: Code reusability, flexibility, simplified code, and maintainability.
	Inheritance’s Role in Polymorphism: Provides the "is-a" relationship, enables subtype polymorphism, and allows method overriding with dynamic dispatch.
	Differences: Inheritance is about structure and reuse, while polymorphism is about behavior and flexibility; inheritance sets up the hierarchy, and polymorphism leverages it at runtime

+ the Media class should implement the Comparable interface

By title, then cost (e.g., COMPARE_BY_TITLE_COST).
By cost, then title (e.g., COMPARE_BY_COST_TITLE).

+ No, you cannot have two ordering rules using only the Comparable interface approach. Here’s why:
	The Comparable interface defines a single natural ordering for a class via the compareTo method. This means you can only implement one ordering rule (e.g., by title then cost) in the compareTo method.
